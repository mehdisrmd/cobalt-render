This repo packages a **yt-dlp download engine** for Render's free web-service tier (service name kept as `cobalt-engine` so the public URL, https://cobalt-engine-w87i.onrender.com, does not change). It replaced the official cobalt API image on 2026-11-13: cobalt 11.7.1 cannot consume the SABR-only formats YouTube now serves this account (`error.api.fetch.fail` on every title, cookies or not), while yt-dlp 2026.10.26 with the Node EJS JS-challenge solver downloads them — proven in a local POC (full 44-minute audio, 42,576,033 bytes, ffprobe-verified) before this swap.

Contents: `Dockerfile` (Python 3.12 + pip-pinned yt-dlp + Node 24 binary + ffmpeg), `server.py` (the authenticated HTTP API, Python stdlib only), `render-start.sh` (boot: converts the dashboard-only `$YT_COOKIES_JSON` from cobalt format into a Netscape `/cookies.txt` for yt-dlp), `render.yaml` (the free `cobalt-engine` service; `API_KEYS_JSON` is sync:false and set manually in the Render dashboard — never committed here). The full API contract lives in [ENGINE-API.md](ENGINE-API.md).

It is Mehdi's private download engine, a stopgap on Render free that feeds his Bale YouTube downloader bot while a permanent free host is sorted out.
