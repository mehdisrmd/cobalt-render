This repo packages the official cobalt API image (`ghcr.io/imputnet/cobalt`) for Render's free web-service tier: the Dockerfile adds a small boot script that writes the API key file from the `API_KEYS_JSON` environment variable, maps Render's `$PORT` and `$RENDER_EXTERNAL_URL` onto cobalt's `API_PORT` and `API_URL`, and enforces API key auth, while `render.yaml` describes the free `cobalt-engine` service (set `API_KEYS_JSON` manually in the Render dashboard — it is never committed here). It runs Mehdi's private cobalt download engine, a one-month stopgap on Render free that feeds his Bale YouTube downloader bot while a permanent free host is sorted out.
